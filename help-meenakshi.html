Getting Telegram set up

Telegram is a free messaging app, like WhatsApp. You only do this once.

  1. On your phone, open the App Store (iPhone) or Play Store (Android) and search for Telegram.

    It's the app with the white paper-plane icon on a light blue circle.

  2. Tap Install, then open it once it's done.

    It will ask for your phone number to set up your account — this is normal, it's how Telegram identifies you.

  3. Once it's open, tap the search icon (magnifying glass) at the top and type:

    @meenshaozbot

  4. Tap on the bot when it appears in the results, then tap Start at the bottom of the screen.

    The first two people to message this bot are approved automatically — after that you're all set, permanently. You won't need to do this again.

  5. You'll see a welcome message with four buttons. This is the main menu — it's where every guide below starts from.

    🛍️ Kiosk mode (sale) 📦 Stock intake (draft) 📊 Reports 🎟️ Vouchers
    If you ever get lost, type /start and send it — this always brings you back here.

Recording a sale

Use this every time you sell something in person.

  1. From the main menu, tap 🛍️ Kiosk mode (sale)

  2. Type the name of the item (e.g. Ajrakh) and send it.

    A photo of each matching item will appear, with the price and how many are in stock.

  3. Under the item's photo, tap ➕ Add to sale, then tap how many the customer is buying.

  4. Selling more than one item? Tap ➕ Add another item and repeat. Otherwise tap ✅ Checkout.

  5. Type the customer's name, send it, then their WhatsApp number, send it.

  6. It will ask: "Coupon code? Type a code, or 'skip' if none."

    If the customer has a voucher code (from a card, an event, or one you made — see Part 4), type it in exactly. Otherwise type skip.
    New: voucher codes now actually work here — if a customer gives you a code, it will reduce the total before you take payment.

  7. It will ask for the amount received — leave this blank (just send an empty message) if they're paying the full price shown.

  8. Tap 💵 Cash or 📱 Card, then tap ✅ Confirm.

    That's it — the sale is saved and you'll see an invoice link you can send the customer on WhatsApp.
3

Adding new stock

Use this when new items arrive, before they can be sold.

  1. From the main menu, tap 📦 Stock intake (draft)

  2. Type the item's name and send it. If something similar already exists, it will show you — tap it if it's a match, or tap ➕ This is a new item if not.

  3. Answer the questions as they come, one at a time: quantity, material, variant/colour, purchase price, sale price, notes.

    Don't know one of these yet? Type skip and move on — you can fix it later.

  4. When it asks for photos, send 1 or 2 clear photos of just that item (nothing else in the picture), then type done.

  5. You'll see ✅ Draft submitted for approval.

    This doesn't go live immediately — it's reviewed on the computer first, then added to real stock. This is by design, so nothing gets added by mistake.
4

Creating a voucher code

Use this to make a one-off discount code — for one customer, or for anyone.

  1. From the main menu, tap 🎟️ Vouchers, then tap 🎟️ Create voucher.

  2. Type a short code for it, e.g. SYDNEY10, and send it.

    Keep it short and easy to say out loud or write on a card.

  3. Tap % Percent off or A$ Flat amount off, then type the number (e.g. 10 for 10%, or 20 for A$20 off).

  4. It will ask if it's for one specific customer. Type their name if it's just for them, or type skip to make it public — anyone can use it.

  5. Type how many days it should stay valid for, e.g. 7 — or leave it blank for the default 7 days.

  6. Done — you'll see a confirmation with the code. Give this code to the customer to use during checkout (Part 2, step 6).

5

Creating an event form

Use this before a market stall or pop-up — it gives every visitor who registers their own unique code, without you handing anything out one by one.

  1. From the main menu, tap 🎟️ Vouchers, then tap 📋 Create event form.

  2. Type the event's name, e.g. Sydney Pop-Up, and send it.

  3. Tap % Percent off or A$ Flat amount off, then type the discount amount.

  4. Type how many days each visitor's code should stay valid after they register — or leave blank for 7 days.

  5. You'll get back a link. Share this however suits the event — put it on a sign, a QR code, or send it directly.

    Anyone who opens the link, types their name and WhatsApp number, gets their own unique code on screen immediately — you don't need to be there for it to work.
